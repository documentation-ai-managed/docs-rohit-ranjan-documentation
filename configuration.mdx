## Backup and Restore

Learn how to backup your configuration and restore it when needed.

```bash
# Backup configuration
curl -H "Authorization: Bearer YOUR_API_KEY" \
     https://api.rohitrnj.com/config/backup > config_backup.json

# Restore configuration
curl -X POST https://api.rohitrnj.com/config/restore \
     -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json" \
     -d @config_backup.json
```
