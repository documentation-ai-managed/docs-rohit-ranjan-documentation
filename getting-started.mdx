## Account Setup

<Steps>
  <Step title="Sign Up" icon="user-plus">
    Visit our website and click on the "Sign Up" button. Fill in your details including email address and password.
    ```bash
    # Sign up via API
    curl -X POST https://api.rohitrnj.com/signup \
      -H "Content-Type: application/json" \
      -d '{"email":"user@example.com","password":"secure123"}'
    ```
  </Step>
  <Step title="Verify Email" icon="mail">
    Check your email for a verification link and click it to activate your account.
  </Step>
  <Step title="Complete Profile" icon="settings">
    Add additional information like your name and organization to complete your profile setup.
  </Step>
</Steps>

## First Project

<Tabs>
  <Tab title="Web Interface" icon="monitor">
    <Steps>
      <Step title="Navigate to Projects" icon="folder">Log in and click on "Projects" in the navigation menu.</Step>
      <Step title="Create New Project" icon="plus">Click the "New Project" button and enter your project details.</Step>
      <Step title="Configure Settings" icon="settings">Set up branding, navigation, and permissions for your project.</Step>
    </Steps>
  </Tab>
  <Tab title="API" icon="code">
    ```javascript
    // Create a new project via API
    const projectData = {
      name: "My Documentation",
      description: "Project documentation",
      theme: "default"
    };
    
    fetch('/api/projects', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(projectData)
    });
    ```
  </Tab>
</Tabs>
