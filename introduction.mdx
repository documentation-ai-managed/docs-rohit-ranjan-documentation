## Quick Setup

<Steps>
  <Step title="Create Account" icon="user">
    Sign up for your Rohit Ranjan Documentation account and verify your email address.
    ```bash
    # Example command to create account
    curl -X POST https://api.rohitrnj.com/accounts \
      -H "Content-Type: application/json" \
      -d '{"email":"user@example.com"}'
    ```
  </Step>
  <Step title="Configure Project" icon="settings">
    Set up your first documentation project with custom branding and navigation.
  </Step>
  <Step title="Add Content" icon="file-text">
    Start adding your documentation pages, API references, and resources.
  </Step>
</Steps>

## API Reference

Our comprehensive API allows you to programmatically manage your documentation. Use our RESTful endpoints to create, update, and retrieve documentation content.

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  // Fetch documentation pages
  const response = await fetch('/api/docs');
  const docs = await response.json();
  console.log(docs);
  ```
  ```python
  # Fetch documentation pages
  import requests
  response = requests.get('/api/docs')
  docs = response.json()
  print(docs)
  ```
</CodeGroup>

## Best Practices

<ExpandableGroup>
  <Expandable title="Content Organization" default-open="false">
    Structure your documentation with clear hierarchies and consistent naming conventions. Use descriptive titles and organize related content together.
  </Expandable>
  <Expandable title="Writing Guidelines" default-open="false">
    Write in clear, concise language. Use active voice and second person perspective. Include practical examples and avoid jargon unless explained.
  </Expandable>
  <Expandable title="Maintenance" default-open="false">
    Regularly review and update your documentation to ensure accuracy. Set up processes for version control and content reviews.
  </Expandable>
</ExpandableGroup>

<Callout kind="tip">Keep your documentation up-to-date to maximize its value for your users and team members.</Callout>
